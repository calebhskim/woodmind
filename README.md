# woodmind

This project contains a simple Mastermind game implemented in JavaScript using the HTML5 canvas. The site is fully static and can be served from any basic web server.

## Playing
Open `index.html` in your browser. Click a color from the palette at the bottom and then click the current row slots to set your guess. Use the **Check** button to submit. Feedback is given as `B` (correct color and position) and `W` (correct color, wrong position).

You have ten attempts to guess the secret combination.
